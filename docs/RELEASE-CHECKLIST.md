# Проверка перед релизом

Автоматические проверки (`npm test`, `npm run smoke`, CI) работают на подставной сети и не
видят изменений настоящих ESPN, FotMob и VK, установщика и автообновления. Этот список
проходится вручную перед публикацией релиза. Результат — какие пункты пройдены, а какие нет
и почему — записывается в [PLAN.md](../PLAN.md), в таблицу проверок.

Нужно: Windows 10/11 x64, российский IP (иначе VK не отдаёт эфиры), идущий или недавний
матч с трансляцией на одном из встроенных каналов — теннисный и футбольный. Если матчей
одного из видов в эти дни нет, его пункты отмечаются «не проверено» с причиной.

## 1. Автоматика

- [ ] `npm test` и `npm run smoke` проходят локально; CI на PR зелёный.
- [ ] Версия в `package.json` и `package-lock.json` повышена.
- [ ] `npm run dist` собран из merge-коммита в `main`; SHA512 и размер exe совпадают
      с `dist/latest.yml`; файлы `src` в `app.asar` совпадают с этим коммитом;
      в `app-update.yml` — репозиторий `match-center`.

## 2. Настоящие источники (запуск из исходников: `npm run app`)

Теннис:

- [ ] **ESPN.** Сегодняшние турниры и матчи на месте; счёт идущего матча совпадает
      с espn.com (с задержкой до минуты); внизу окна «счёт ESPN от ЧЧ:ММ» обновляется.
- [ ] **ESPN недоступен.** Отключить сеть на 2 минуты: расписание остаётся, полоса
      «ESPN сейчас недоступен — показано расписание от ЧЧ:ММ», время внизу не двигается,
      пометка «(не обновляется)». После включения сети — снова свежее время.

Футбол (клавиша **2** или вкладка «Футбол»):

- [ ] **FotMob.** Матчи выбранных турниров на месте, названия команд и турниров по-русски,
      логотипы видны; счёт и минута идущего матча совпадают с fotmob.com (с задержкой
      до минуты); внизу окна «счёт FotMob от ЧЧ:ММ» обновляется.
- [ ] **Турнир по номеру.** В настройках добавить турнир по числу из ссылки
      `fotmob.com/leagues/…`: в списке появляется его русское название, после сохранения —
      его матчи в расписании.
- [ ] **FotMob недоступен.** Как у ESPN: расписание остаётся, полоса «FotMob сейчас
      недоступен», пометка «(не обновляется)».

Оба вида:

- [ ] **Переключение.** Вкладки и клавиши **1**, **2** меняют вид; выбранный день
      сохраняется; заголовок окна — «Матч-центр | Теннис» или «Матч-центр | Футбол» с версией;
      после перезапуска открыт тот же вид.
- [ ] **VK.** У открытого вида индикатор каналов зелёный, в панели каналов все его встроенные
      каналы «через API». После переключения эфиры другого вида появляются в течение
      нескольких секунд.
- [ ] **Привязка эфиров.** У идущего матча есть кнопка канала с меткой LIVE; у прошедших —
      записи; у матча без трансляции — «Искать в VK». Проверить в каждом виде.
- [ ] **Свои настройки у видов.** ★ у игрока и ★ у команды, свой канал, написание:
      сохраняются в своём виде спорта и не появляются в другом.
- [ ] **Отчёт.** «Скопировать отчёт» в панели каналов: в тексте версия, ОС, разделы
      «Теннис» (ESPN по турам, каналы) и «Футбол» (FotMob, каналы или «каналы не
      опрашиваются»); нет имени пользователя Windows, полных путей, параметров адресов,
      имён своих каналов.

## 3. Воспроизведение (глазами и на слух)

- [ ] Клик по LIVE открывает окно плеера поверх остальных, 16:9, видео идёт — в теннисе
      и в футболе.
- [ ] Первое окно — со звуком на 50%, второе — без звука; после закрытия всех следующее
      снова со звуком. Переключение вида спорта открытые окна не закрывает и не перезапускает.
- [ ] Качество в первые секунды не ниже 720p (меню качества плеера VK).
- [ ] Ctrl+клик по каналу открывает трансляцию в браузере.

## 4. Установка и обновление

- [ ] **Установка поверх предыдущей версии.** Поставить новый exe поверх установленной
      прежней: настройки, избранное и каналы обоих видов сохранились; в заголовке окна
      новая версия.
- [ ] **Автообновление.** На машине с предыдущей версией после публикации релиза:
      полоса «Доступна версия X» → «Скачать» → прогресс → «Установить» → приложение
      перезапускается уже новой версией.
- [ ] **Трей и автозапуск.** Крестик прячет окно в трей; «Выход» из меню трея закрывает
      приложение; при включённом автозапуске после входа в Windows приложение в трее.
- [ ] **Уведомление.** Отмеченный колокольчиком матч даёт уведомление только при фактическом
      начале (заранее — нет); в тексте назван вид спорта. Клик открывает матч; если матч
      другого вида спорта — окно переключается на него.

## 5. Переход с прежних приложений (для 3.0.0 и пока прежние версии встречаются)

Перед проверкой сохранить копии `%APPDATA%\MatchCenter\settings.json` и
`%APPDATA%\TennisCenter\settings.json`.

- [ ] **Поверх футбольного «Матч-центра» 2.4.0.** Установщик ставится на его место (один
      значок в «Пуске»). Первым открывается футбол; турниры, свои каналы, избранное
      и написания на месте; рядом с `settings.json` появился `settings.v1.json`.
- [ ] **Настройки тенниса забраны.** При установленном «Матч-центр Теннис»: во вкладке
      «Теннис» — его избранное, разряды, свои каналы и написания; в `settings.json` есть
      `"imported": ["tennis"]`; файл в `%APPDATA%\TennisCenter` не изменился; теннисное
      приложение по-прежнему запускается.
- [ ] **Один раз.** Убрать игрока из избранного в новом приложении, перезапустить —
      он не вернулся.
- [ ] **Чистая установка** (нет ни одной из папок): открывается теннис, оба вида на
      встроенных настройках.
- [ ] **Только теннис был установлен:** открывается теннис с его избранным, тема и размер
      окна — как в теннисном приложении.
- [ ] **Возврат.** Установить 2.4.0 поверх, положить `settings.v1.json` на место
      `settings.json`: футбольное приложение работает с прежними настройками.
- [ ] **Обновление 2.4.0 → 2.5.0 → 3.0.0** (когда 2.5.0 выпущена): установленная 2.4.0
      сама находит 2.5.0, а та — 3.0.0 в репозитории `match-center`.
- [ ] **Полоса в теннисе 1.1.0** (когда выпущена): «Теннис теперь в Матч-центре» со ссылкой
      на установщик; ссылка открывает страницу релиза.

Пункты, которые проверить нельзя (нет идущих матчей, нет второй машины), так и
отмечаются — «не проверено», с причиной, а не пропускаются молча.
