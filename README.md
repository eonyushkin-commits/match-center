# Матч-центр

Расписание, счёт и трансляции из каналов VK Видео в одном окне — для двух видов спорта:

- **Теннис** — мужские и женские матчи ATP и WTA, расписание и счёт из ESPN;
- **Футбол** — английские турниры (и любые другие по выбору), расписание и счёт из FotMob.

Под каждым матчем — кнопки каналов; плеер VK открывается отдельным окном. Вид спорта
переключается в шапке окна. Каналы, турниры и избранное у каждого вида свои.

Windows 10/11, x64. Работает без аккаунтов и токенов. Трансляции доступны только с российского IP.

Приложение объединяет два прежних: футбольный «Матч-центр» и «Матч-центр Теннис». Оно
продолжает футбольное (то же имя и та же папка настроек), а настройки тенниса забирает само
при первом запуске — см. [«Переход с прежних приложений»](#переход-с-прежних-приложений).
Что сделано и что осталось — в [PLAN.md](PLAN.md).

## Установка и обновления

Установщик — на [странице последней версии](https://github.com/eonyushkin-commits/match-center/releases/latest)
(`match-center-X.Y.Z-setup.exe`). Он не подписан, поэтому SmartScreen попросит подтверждения:
«Подробнее» → «Выполнить в любом случае». Ставится в профиль пользователя, права администратора не нужны.

**Обновления — в два шага.** Приложение проверяет GitHub Releases при запуске и раз в 6 часов.
Когда выходит новая версия, над расписанием появляется полоса «Доступна версия X.Y.Z» со ссылкой
«Что нового» и кнопкой **«Скачать»**; во время загрузки виден процент. Потом кнопка сменится на
**«Установить»** — приложение перезапустится уже новой версией. Полосу можно скрыть крестиком
на любом шаге; скачанная, но не установленная версия поставится сама при выходе. Проверить
вручную — **Alt** → «Матч-центр» → «Проверить обновления».

## Возможности

### Вид спорта

- **Переключатель «Теннис / Футбол»** — в шапке окна; клавиши **1** и **2** делают то же.
  Выбранный день при переключении сохраняется, поиск сбрасывается. Открытый вид запоминается.
- **Свои у каждого вида**: каналы VK, турниры (у тенниса — разряды), избранное, отмеченные
  матчи и написания. **Общие**: тема, фильтры, порядок матчей, режим без спойлеров,
  частота опроса каналов, уведомления, трей и автозапуск.
- **Каналы VK читаются только у открытого вида.** После переключения эфиры появляются через
  секунду-другую. Уведомления о матчах избранных приходят по обоим видам.

### Расписание

- **Полоса дат** — семь дней, при запуске сегодня в середине. **‹** **›** и клавиши **←** **→**
  переключают на день назад или вперёд. Листать можно от 10 дней назад до 10 дней вперёд.
  В полночь «Сегодня» само переходит на новый день.
- **Порядок.** Обычно разделы идут один за другим в порядке списка из настроек. Кнопка с часами
  в шапке ставит матчи **по времени начала**. Выбор запоминается.
- **Свежесть счёта** — внизу окна: «счёт ESPN от 14:58» (у футбола — «счёт FotMob от…»), время
  последнего ответа источника на выбранный день. Если источник не отвечает, показывается
  прежнее расписание, время не меняется, а рядом появляется пометка «не обновляется» и полоса
  над списком; для данных не за сегодня время — с датой.
- **Сейчас в эфире** — блок над расписанием (для сегодняшнего дня) с матчами, которые идут
  и у которых есть живая трансляция.
- **Фильтры** «С трансляцией», «Идут сейчас», «★ Избранное» и **поиск** по участнику или турниру.
  Фильтры запоминаются.

**Теннис**

- **Турниры** — доступные в ESPN турниры, которые идут в выбранный день. В настройках выбираются
  **разряды**: «Мужчины» и «Женщины»; одиночные включены, парные по умолчанию выключены.
  В табло входят и четыре турнира **Большого шлема**; микст не включён.
- **Уровень турнира** — в шапке раздела: Grand Slam, ATP Finals / WTA Finals, ATP / WTA 1000,
  500 и 250. Показываются только турниры этих уровней; WTA 125, Next Gen ATP Finals и командные
  турниры скрыты. Уровень берётся из справочника сезона (см. «Как это работает»); если
  справочника на сезон ещё нет, показываются все турниры ESPN, а метка есть только у Шлемов.
  По уровню можно искать: «500», «WTA 1000».
- **День — по часам компьютера.** Ночной матч в Америке стоит в том дне, на который он
  приходится у вас. Идущий матч, начатый до полуночи, остаётся и в сегодняшнем списке.
- **Счёт по сетам** обновляется сам (с задержкой до минуты): геймы в каждом сете, очки
  тай-брейка мелко сверху, точка у подающего; выигранные сеты и победитель выделены.
  Счёта внутри гейма нет.
- **Статус**: время начала, номер идущего сета, «Оконч.», «Отказ», «Неявка», «Отмена», «Перенос».
  Если время ещё не назначено («после предыдущего матча»), вместо него прочерк;
  такие матчи стоят в конце списка.
- **Под названием турнира** — раунд и корт; перед именем игрока — номер посева.
- **Имена игроков** — как в ESPN, на английском; искать можно и по-русски.

**Футбол**

- **Турниры** по умолчанию: английские Премьер-лига, Чемпионшип, Кубок Англии, Кубок английской
  лиги, Суперкубок Англии и российская ФНЛ. В настройках они подписаны со страной: «Англия ·
  Премьер-лига», «Россия · ФНЛ». Любой другой турнир FotMob добавляется в настройках по номеру из его
  адреса на сайте (`fotmob.com/leagues/42/…` → 42).
- **Русские названия** команд и турниров, логотипы клубов и лиг.
- **Тур или стадия** — компактная метка рядом с названием турнира: «11-й тур»,
  «4-й раунд», «Полуфинал», «Финал», если FotMob передал эти сведения.
  Если в один день идут разные туры, у каждого матча есть уточнение.
- **Счёт** обновляется сам (с задержкой до минуты); у завершённого матча победитель выделен.
- **Статус** — как его отдаёт FotMob: минута матча («67’»), «HT», «FT», «AET», «Pen».
- Группы и этапы одного турнира (чемпионат мира, сезонные этапы Чемпионшипа) собраны
  в один раздел.

### Трансляции

- **Каналы** по умолчанию. Теннис: ПраймСпорт, Sportcast Теннис, BB Tennis, Больше! Теннис,
  Теннис Тайм. Футбол: Английский Акцент, АПЛ Навсегда, Sportcast, ВЫШЛИ!, Лига PARI.
  Можно добавить любой канал VK Видео — отдельно для каждого вида спорта.
- **Метки**: **LIVE** — идёт сейчас, рядом число зрителей; **скоро** — запланирована;
  **запись** — закончилась.
- **Порядок кнопок**: идущие всегда впереди, дальше запланированные, затем записи.
  Несколько эфиров одного канала нумеруются: «Sportcast», «Sportcast 2».
- Наведите на кнопку — увидите полный заголовок эфира. Если трансляций у матча нет —
  кнопка «Искать в VK».

### Плеер

- Клик по каналу открывает официальный плеер VK **в отдельном окне поверх остальных**,
  с пропорциями 16:9. Можно открыть несколько матчей, в том числе разных видов спорта.
  Закрывается крестиком самого окна.
- Первое окно открывается с громкостью **50%**, второе и последующие — **без звука**.
  Громкость и звук можно менять в самом плеере. После закрытия всех окон следующая
  трансляция снова открывается на 50%; закрытие первого окна само не включает звук в остальных.
- Плеер открывается в режиме VK **«Высокое качество»** (вместо «Автоматически»).
  Качество можно сменить в меню плеера; выбор действует до выхода из приложения.
- Обновление расписания, фильтры и переключение вида спорта не перезагружают видео.
  Записи открываются с начала; позиция просмотра после закрытия окна не сохраняется.
- **Ctrl + клик** по каналу открывает эфир во внешнем браузере.
- Отдельного браузерного режима нет: приложение работает только как окно Electron.

### Без спойлеров

- Кнопка «Без спойлеров» рядом с фильтрами прячет счёт и победителя (в теннисе — и подающего),
  чтобы смотреть запись, не зная результата. Счёт одного матча открывается нажатием на **?**.

### Избранное и уведомления

- **★** рядом с игроком (в одиночном разряде) или командой — в избранное: уведомления обо всех
  матчах, у игрока — в том числе парных.
- **🔔** под временем начала — уведомить об одном матче.
- **Уведомления Windows**: только **когда матч фактически начался** (заранее не напоминают).
  Пока матч задерживается, приложение проверяет его раз в минуту. В уведомлении назван вид
  спорта; клик открывает этот вид и матч, а если трансляция идёт — сразу и плеер.
  Канал трансляции в уведомлении назван, только если этот вид спорта сейчас открыт в окне.

### Трей и автозапуск

- Крестик окна **прячет приложение в трей** — уведомления продолжают приходить. Выйти — правой
  кнопкой по значку → «Выход» или **Ctrl+Q**. Трей можно выключить в настройках.
- **Запуск вместе с Windows** (выключен по умолчанию) — приложение стартует свёрнутым в трей.

### Клавиши

| Клавиша | |

| **1** **2** | вид спорта: теннис / футбол |
| **←** **→** | предыдущий / следующий день |

## Настройки

Окно настроек (кнопка справа вверху или **,**) показывает настройки **открытого вида спорта**
и общие:

- **каналы** вида — добавить по ссылке `vkvideo.ru/@name`, переименовать, выключить встроенный,
  удалить добавленный;
- **разряды** (теннис) — «Мужчины» и «Женщины»; парные по умолчанию выключены;
- **турниры** (футбол) — встроенные и любые другие по номеру FotMob;
- **написание игроков или команд** — если эфир не привязался к матчу, потому что канал пишет
  по-своему: `Соболенко = Сабаленка`, `Манчестер Юнайтед = МЮ, Ман Юнайтед`;
- общие: **частота опроса каналов** (от 30 секунд до 5 минут), **уведомления**, **трей**,
  **запуск вместе с Windows**.

Файл — `%APPDATA%\MatchCenter\settings.json` (**Alt** → меню → «Папка с настройками»).
В нём хранятся **только отличия** от встроенных настроек. Если правите руками — выйдите из
приложения (из трея), иначе оно перезапишет файл при следующем сохранении.

```json
{
  "version": 2,
  "refreshSeconds": 120,
  "ui": { "theme": "dark", "sport": "football", "hideScores": false, "leaguesByTime": true },
  "imported": ["tennis"],
  "sports": {
    "tennis": {
      "channels": [
        { "screenName": "my_channel", "label": "Мой канал" },
        { "screenName": "bbtennis_live", "disabled": true }
      ],
      "leagues": [2, 1, 4],
      "teamAliases": { "Соболенко": ["Сабаленка"] },
      "favorites": [{ "id": 9820, "name": "Mirra Andreeva" }]
    },
    "football": {
      "leagues": [47, 48, 42],
      "favorites": [{ "id": 9825, "name": "Арсенал" }]
    }
  }
}
```

- Общие настройки лежат в корне, настройки вида спорта — в `sports.<вид>`.
- `ui.sport` — вид, открытый в окне.
- `leagues` у тенниса — разряды и их порядок: 1 — мужчины одиночный, 2 — женщины одиночный,
  3 — мужчины парный, 4 — женщины парный. У футбола — номера турниров FotMob и их порядок.
- `imported` — из каких прежних приложений настройки уже забраны (см. ниже).

### Переход с прежних приложений

- **Футбольный «Матч-центр»** обновляется на месте: та же папка `%APPDATA%\MatchCenter`.
  Его файл настроек (без `version`) при первом запуске переводится в новый вид, прежний
  остаётся рядом как `settings.v1.json`. Первым откроется футбол.
- **«Матч-центр Теннис»** — отдельное приложение со своей папкой `%APPDATA%\TennisCenter`;
  новое встаёт рядом, а не поверх. При первом запуске оно один раз забирает оттуда каналы,
  разряды, написания и избранное тенниса. Папка тенниса не меняется; прежнее приложение
  можно удалить, когда оно станет не нужно. Избранное, которое вы потом уберёте в новом
  приложении, обратно не вернётся.
- Вернуться на прежнюю футбольную версию: установить её и положить `settings.v1.json`
  на место `settings.json`.

## Отчёт для диагностики

Если что-то не работает, нажмите на индикатор каналов VK в шапке → **«Скопировать отчёт»**
(или **Alt** → меню → «Скопировать отчёт для диагностики») и вставьте текст в сообщение
о проблеме. В отчёте:

- версии приложения, Electron и ОС, установленная это версия или запуск из исходников;
- по каждому виду спорта — его источник (ESPN по турам, FotMob по видам запросов): время
  последнего успешного ответа и последней ошибки;
- каждый канал VK: работает ли, каким способом прочитан, когда проверен и когда были
  последние данные, неудачи и пауза запасного чтения, текст ошибки; у вида спорта, который
  не открыт в окне, — что его каналы не опрашиваются;
- предупреждения и только **счётчики** настроек: сколько каналов, турниров, избранного.

В отчёт не попадают пути с именем пользователя (заменяются на `<userData>`, `~`, `<user>`),
параметры адресов, токены, e-mail и содержимое настроек: имена избранных, свои написания,
отмеченные матчи. Добавленные вами каналы обозначены как «свой канал 1». Время в отчёте — UTC.

## Как это работает

**Теннис: расписание и счёт** — неофициальный API табло ESPN (`site.api.espn.com`), без ключа.
Запрос «на день» возвращает целиком турниры, идущие в этот день по американскому времени;
нужный день приложение выбирает само, а чтобы не потерять ночные матчи, спрашивает ещё и
соседние дни. Челленджеров и ITF в табло ESPN нет.

**Теннис: уровни турниров** ESPN не отдаёт (только признак Шлема), поэтому в приложении есть
справочник `src/sports/tennis/tournaments.json`: для каждого сезона и тура — номер турнира ESPN
(часть `id` до дефиса, например `970` в `970-2026`), уровень и название для удобства правки.
Справочник составлен по календарям сезона в Википедии (ссылки — в поле `source`) и правится
вручную раз в год. У общего турнира уровни мужчин и женщин разные (Брисбен: ATP 250 и WTA 500),
поэтому туры записаны отдельно.

**Футбол: расписание и счёт** — неофициальный API FotMob (`www.fotmob.com`), без ключа: матчи
дня в вашем часовом поясе, словарь русских названий команд и турниров и справочник всех
турниров (для добавления по номеру). Названия и справочник обновляются раз в сутки.

**Обновление.** Идущие матчи обновляются раз в минуту. Окно ничего не опрашивает: приложение
само сообщает ему о новых эфирах и изменившемся счёте. Пока окно скрыто в трей или свёрнуто,
расписание для него не запрашивается; источник опрашивается только ради уведомлений и только
если у этого вида спорта есть избранное или отмеченные матчи. Если источник не ответил,
показывается расписание, полученное ранее.

**Каналы VK** читаются раз в минуту (настраивается), только у открытого вида спорта. Приложение
делает те же запросы к API VK Видео, что и сайт для незалогиненного посетителя. Каждую минуту
читаются свежие эфиры и те, что идут или ожидаются в ближайшие сутки; остальное (записи примерно
за месяц и эфиры, назначенные позже) — раз в 15 минут. Если API не ответил, канал читается
запасным способом — страница открывается в скрытом окне.

**Привязка трансляции к матчу** — по участникам в заголовке эфира; между ними может стоять
тире, дефис, `vs`, «против» или `x`. Лишние слова отсекаются, опечатки прощаются. Правила у
видов спорта свои:

- *Теннис.* Игроки ищутся в любой части заголовка между `|` или ` / `. Каналы пишут по-русски,
  ESPN — по-английски, поэтому есть словарь русских имён (`src/sports/tennis/players.json`:
  топ-150 ATP и WTA и часть парников); остальных приложение узнаёт, переводя заголовок
  в латиницу. Пара привязывается, только если в заголовке есть оба игрока каждой стороны.
  Учитываются эфиры, созданные от двух суток до матча до двенадцати часов после его начала.
- *Футбол.* Команды ищутся в любой части заголовка между `|`. Совпадение только по общим словам
  («Юнайтед», «Сити», «Манчестер») не засчитывается. Учитываются эфиры, созданные от пяти дней
  до матча до шести часов после начала.

**Плеер** — официальная страница плеера VK (`video_ext.php`), открытая отдельным окном напрямую,
а не во встроенном iframe: iframe на локальной странице VK отказывается воспроизводить. Окно
изолировано от приложения; сессия живёт только в памяти.

**Сеть.** Приложение обращается только к ESPN (`site.api.espn.com`, флаги — `a.espncdn.com`),
FotMob (`www.fotmob.com`, логотипы — `images.fotmob.com`), VK (`login.vk.ru`, `api.vkvideo.ru`,
`vkvideo.ru`) и GitHub (обновления). Никакой статистики не отправляет. Внутри приложения
работает локальный сервер только на `127.0.0.1`.

**Россия.** VK отдаёт эти каналы только на российский IP.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| Трансляций нет, точка у «N эфиров» красная | Нужен российский IP — выключите VPN или смените страну |
| В плеере «Видео недоступно» | Откройте эфир во внешнем браузере через Ctrl + клик по каналу |
| Трансляция есть на канале, но не под матчем | Добавьте написание игрока или команды в настройках; пока — «Искать в VK» |
| Теннисного матча нет в расписании | Это челленджер или ITF — их нет в ESPN; либо выключен его разряд |
| Футбольного матча нет в расписании | Его турнир не выбран — добавьте турнир в настройках по номеру FotMob |
| Счёт или эфиры кажутся устаревшими | Кнопка **↻** или клавиша **R** |
| «ESPN (FotMob, VK) изменил формат ответа» | Сайт поменял свои данные, и эта версия их не понимает — нужна новая версия приложения |
| «Не удалось сохранить настройки» | Файл настроек занят или недоступен для записи; приложение работает на прежних настройках |
| Нет уведомлений | Игрок или команда в ★ либо матч отмечен 🔔, уведомления включены, в Windows выключен «Не беспокоить». Уведомления приходят, пока приложение запущено — окно может быть закрыто в трей |
| После обновления нет избранного тенниса | Оно забирается из `%APPDATA%\TennisCenter\settings.json` один раз, при первом запуске; проверьте, что этот файл был на месте |

## Запуск из исходников

Нужен Node.js 22+.

```
npm install
npm run app
```

Из исходников приложение использует отдельный профиль `%APPDATA%\MatchCenter-dev`, а настройки
тенниса при первом запуске забирает из `%APPDATA%\TennisCenter-dev`, если она есть.

Проверки: `npm test` — ядро и модули страницы; `npm run smoke` — само приложение (окно, трей,
переключение вида спорта, прямые окна плеера, настройки, выход) на подставных данных в отдельном
временном профиле.

На каждый PR и push в `main` GitHub Actions запускает те же проверки на Windows
([.github/workflows/ci.yml](.github/workflows/ci.yml)): `npm test` на Node.js 22 и 24
и `npm run smoke`. Настоящие ESPN, FotMob и VK в CI не проверяются — сеть там подставная.
Их, воспроизведение, установку и автообновление перед релизом проверяют вручную по
[docs/RELEASE-CHECKLIST.md](docs/RELEASE-CHECKLIST.md).

Теннисные справочники — уровни турниров (раз в год, до января) и русские имена игроков —
обновляются вручную по [docs/REFERENCE-DATA.md](docs/REFERENCE-DATA.md).

`npm run dist` собирает установщик в `dist/`: `match-center-X.Y.Z-setup.exe`. Версия берётся
из `package.json`.

### Как устроен код

- `src/core/` — общее ядро: настройки, опрос каналов VK, лента для страницы, сервер,
  уведомления, отчёт. О конкретном виде спорта не знает.
- `src/sports/<вид>/` — вид спорта в ядре: источник расписания, сборка дня, сопоставление
  эфиров, настройки по умолчанию. Описание вида — `index.mjs`, список видов — `src/sports/index.mjs`.
- `src/web/` — страница; `src/web/sports/<вид>.mjs` — как вид выглядит: строка матча, шапка
  турнира, тексты.
- `src/electron/` — оболочка: окна, трей, уведомления, обновление.

Как объединялись два приложения и какие решения приняты — [docs/MERGE-PLAN.md](docs/MERGE-PLAN.md).

Своего значка у приложения нет: окна, трей, уведомления и установщик показывают стандартный
значок Electron.
